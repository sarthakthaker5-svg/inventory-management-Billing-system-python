# Inventory Management Billing System

Desktop-based Inventory, Billing, and Employee Management System built with Python Tkinter and SQLite.

## Features
- Employee Management
- Billing System
- Inventory Tracking
- SQLite Database
- GUI Interface
- CRUD Operations

## Technologies Used
- Python
- Tkinter
- SQLite
